A sleek, high-performance To-Do List application built as part of my Software Engineering (BSSE) learning roadmap. This project focuses on modern UI/UX principles and advanced DOM manipulation using Vanilla JavaScript.

🛠️ Tech Stack
HTML5: Semantic structure.

Tailwind CSS: For the "White Glass" aesthetic and responsive layout.

Vanilla JavaScript: Core logic, event handling, and DOM manipulation.

✨ Key Features
Glassmorphism UI: A modern, semi-transparent design with orange accents.

Dynamic Task Management: Add, edit, and delete tasks in real-time without page refreshes.

State Tracking: Interactive completion toggles and "editing mode" transitions.

Professional Branding: Custom footer and responsive design.

🧠 Learning Objectives (Phase 1)
This project was completed to master the following concepts:

Event Listeners: Handling clicks, key presses (Enter key), and blur events.

Element Creation: Dynamically generating HTML nodes via JavaScript.

State Management: Using CSS classes to track and change the state of UI elements.

Responsive Layouts: Implementing a footer that stays anchored at the bottom using Flexbox.
